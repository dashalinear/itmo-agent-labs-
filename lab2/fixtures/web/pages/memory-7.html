Долговременная память агента: FAQ

Память о пользователе обновляют явными операциями записи, а не неявно из каждого сообщения.

Агент должен различать факты из памяти и подтверждённые факты из документов.

Кратковременная память — это история сообщений текущего потока, долговременная — данные между потоками.

Записи памяти снабжают временем создания и источником, чтобы устаревшие факты можно было отбросить.

Ограничение: Векторная память не гарантирует точного совпадения фактов.
