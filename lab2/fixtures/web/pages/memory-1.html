Долговременная память агента: обзор

Записи памяти снабжают временем создания и источником, чтобы устаревшие факты можно было отбросить.

Агент должен различать факты из памяти и подтверждённые факты из документов.

Векторный поиск по памяти находит записи, похожие по смыслу на текущий запрос.

Долговременную память хранят как документы с пространствами имён, например по пользователю.

Ограничение: Векторная память не гарантирует точного совпадения фактов.

Материал подготовлен для учебного набора «хранение состояния LLM-агентов», страница memory-1.
