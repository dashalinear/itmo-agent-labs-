## Цель
Провести автономное веб-исследование (research_web) по теме управления состоянием LLM-агентов. Ключевые аспекты: чекпоинты, бэкенды хранения, долговременная память, компактификация контекста, durable execution, идемпотентность, схема состояния и безопасность.

## Ограничения пользователя
- Собрать очередь из **>=50 URL** (статус: выполнено, найдено 55).
- Прочитать **>=5** самых релевантных страниц (web_fetch) (статус: выполнено, прочитано 10).
- Сохранить **>=6** evidence с точными цитатами (статус: выполнено, сохранено 16).
- Написать разделы обзора: approaches, limitations, comparison, unverified (объем **<=900 слов**).
- Завершить задачу через `complete_task`.

## Решения и договорённости
- Использовать навык `research_web` для автономного поиска без заранее заданного списка URL.
- Разбить тему на 3-6 аспектов и сформулировать специфические запросы (RU/EN).
- Отслеживать дубликаты и отклонять нерелевантные источники через `select_sources`.
- Останавливаться при выполнении критериев TASK CONTRACT или исчерпании полезных источников.
- При ошибке `quote_not_found` использовать `read_artifact` для получения точного текста страницы перед повторным сохранением evidence.
