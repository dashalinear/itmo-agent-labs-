## Подтверждённые факты (с источниками)
- Чекпоинт хранит значения каналов, версию, ожидающие узлы; `thread_id` связывает последовательность (URL: `http://127.0.0.1:8765/p/checkpoint-1`, ev_29043dc075f7).
- Полная история чекпоинтов быстро увеличивает объём базы (URL: `http://127.0.0.1:8765/p/checkpoint-1`, ev_60820d54ea9c).
- SQLite для одного процесса; PostgreSQL для нескольких; сетевое хранилище добавляет задержку (URL: `http://127.0.0.1:8765/p/backends-1`, ev_9583bea2990c, ev_a8a6b26297ee).
- Память хранят как документы с пространствами имён; векторный поиск не гарантирует точности (URL: `http://127.0.0.1:8765/p/memory-1`, ev_165272c6c868).
- Summary сохраняет цель, ограничения, решения, факты; сжимают только завершённые фрагменты (URL: `http://127.0.0.1:8765/p/compaction-1`, ev_9745d44c3bb6).
- Рекурсивная суммаризация без ограничений может зациклиться (URL: `http://127.0.0.1:8765/p/compaction-1`, ev_e37467548bca).
- Durable execution: недетерминированные действия в activities; не делает внешние эффекты идемпотентными (URL: `http://127.0.0.1:8765/p/durable-2`, ev_bd24faf743bb).
- Идемпотентность: ключ из устойчивых признаков; реестр операций; чекпоинт не знает о побочных эффектах (URL: `http://127.0.0.1:8765/p/idempotency-3`, ev_2d2cc1118721, ev_660ff884fbf8).
- Схема: версия рядом с данными; несовместимые изменения ломают старые чекпоинты (URL: `http://127.0.0.1:8765/p/schema-1`, ev_8916e7591ba3).
- Безопасность: секреты хранят отдельно; шифрование не защищает от утечки через логи (URL: `http://127.0.0.1:8765/p/security-1`, art_0aea0a4dc9a8cd78c04f).
