## Цель
Изучить документы в `data/search` по теме поиска: выделить подходы, ограничения и спорные утверждения. Собрать обзор (≤1200 слов) с обязательными разделами: approaches, limitations, disputed, decisions, summary. Найти и дословно процитировать решения АС-01, АС-02, АС-03, решение кафедры о метрике качества и разбор INC-2026-017. Проиндексировать 3 решения АС в Elasticsearch через MCP (build_excerpts, upsert_excerpts) и проверить их наличие через search_excerpts.

## Ограничения пользователя
- [C1] Каждый проверяемый вывод обзора ссылается на документ и страницу через evidence.
- [C2] Использовать только документы из data/search, без интернета.
- [C3] Обзор не длиннее 1200 слов.
- [C4] Спорные утверждения — отдельным разделом, с аргументами за и против.
- [C5] Решения архитектурного совета (АС-01, АС-02, АС-03) привести дословно с номером страницы.
