## Цель
Провести автономное веб-исследование (research_web) по теме управления состоянием и персистентности памяти в LLM-агентах. Задача включает поиск источников, их отбор, полное чтение страниц, сбор верифицированных цитат (evidence) и написание отчета с разделами: подходы, ограничения, сравнение, непроверенные утверждения.

## Ограничения пользователя
- Требуется использовать навык `research_web`.
- Необходимо сформулировать 3-6 аспектов темы и выполнить поисковые запросы.
- Обязательна отборка источников с указанием причин (queue/reject).
- Минимум 5 полностью прочитанных страниц.
- Минимум 6 цитат (evidence) для верификации фактов.
- Отчет должен содержать разделы: approaches, limitations, comparison, unverified.
- Завершение задачи через `complete_task` или `stop_partial` при достижении критериев или исчерпании лимитов.

## Решения и договорённости
- План работы утвержден: 1) Поисковые запросы (3+), 2) Отбор источников, 3) Чтение 5+ страниц, 4) Сбор 6+ цитат, 5) Написание разделов отчета, 6) Завершение задачи.
- Стратегия поиска: использование русскоязычных и англоязычных запросов.
- При сбое поискового бэкенда (Yahoo) принято решение переходить к прямому чтению известных URL-адресов документации и сайтов.
- В случае тайм-аутов на GitHub Pages и Docs, фокус смещен на корпоративные блоги (Anthropic, LangChain) и исследовательские статьи.
- Для страниц с большим объемом текста (offloaded) используется инструмент `read_artifact` с параметрами `start_line` и `max_lines` для постраничного чтения.

## Подтверждённые факты (с источниками)
*Примечание: В текущем фрагменте нет сохраненных через `save_evidence` цитат, но из прочитанных артефактов извлечены следующие данные:*
- **LangGraph**: Описан как фреймворк оркестрации агентов для надежных AI-агентов. Поддерживает human-in-the-loop проверки, модерацию и контроль качества.
  - *Источник*: `https://www.langchain.com/langgraph` (артефакт `art_332c17965499bb5633f9`, заголовок: "LangGraph: Agent Orchestration Framework for Reliable AI Agents").
- **Deep Agents**: Описан как open-source агентный harness, предназначенный для автономных агентов, работающих над сложными задачами (исследования, кодирование, многошаговые workflows) в течение длительного времени. Предоставляет примитивы для разбивки сложных целей (Planning tools).
  - *Источник*: `https://www.langchain.com/deep-agents` (артефакт `art_f880c6a6af0fb92d3519`, заголовок: "Deep Agents: Open Source Agent Harness | LangChain").
- **LangChain**: Провела раунд финансирования Series C на сумму $300M при оценке $3B.
  - *Источник*: Ссылка в навигации на `https://www.langchain.com/blog/series-c` (найдена в обоих прочитанных артефактах).
- **Anthropic (Building effective agents)**: Базовым строительным блоком агентных систем является LLM, усиленный дополнениями (retrieval, tools, memory). Модели могут активно использовать эти возможности, генерируя запросы, выбирая инструменты и определяя, какую информацию сохранять.
  - *Источник*: `https://www.anthropic.com/research/building-effective-agents` (артефакт `art_86a07c9a784f9c3cac84`, строки 64-65).
- **Anthropic (Building effective agents)**: Рекомендуется использовать Model Context Protocol (MCP) для интеграции с экосистемой сторонних инструментов. Описаны паттерны: Prompt chaining (разбиение задачи на последовательность шагов) и Evaluator-optimizer (генерация ответа одной моделью и оценка другой в цикле).
  - *Источник*: `https://www.anthropic.com/research/building-effective-agents` (артефакт `art_86a07c9a784f9c3cac84`, строки 68, 108-109).
- **Anthropic (Building effective agents)**: Рекомендуется начинать с простейших решений и увеличивать сложность только при необходимости. Разработчикам советуют использовать LLM API напрямую, а при использовании фреймворков — понимать внутреннюю логику кода.
  - *Источник*: `https://www.anthropic.com/research/building-effective-agents` (артефакт `art_86a07c9a784f9c3cac84`, строки 143-144 и финальный фрагмент).
