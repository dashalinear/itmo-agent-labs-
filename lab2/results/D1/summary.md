## Цель
Изучить документы в `data/search` по теме информационного поиска: выделить подходы, ограничения и спорные утверждения. Собрать обзор (≤1200 слов) с обязательными разделами: approaches, limitations, disputed, decisions, summary. Найти и дословно привести решения АС-01, АС-02, АС-03, решение кафедры о метрике качества и разбор инцидента INC-2026-017.

## Ограничения пользователя
- [C1] Каждый проверяемый вывод обзора ссылается на документ и страницу через evidence.
- [C2] Использовать только документы из data/search, без интернета.
- [C3] Обзор не длиннее 1200 слов.
- [C4] Спорные утверждения — отдельным разделом, с аргументами за и против.
- [C5] Решения архитектурного совета (АС-01, АС-02, АС-03) привести дословно с номером страницы.

## Решения и договорённости
- Использовать навык `analyze_large_docs`: инвентаризация → поиск → чтение страниц → evidence → секции → проверка критериев.
- Не читать большие файлы целиком, только целевые диапазоны строк.
- Критерии завершения: min_evidence=8, evidence_in_every_scope_document=true, required_sections=["approaches", "limitations", "disputed", "decisions", "summary"], verbatim_quotes в разделе "decisions" для кодов АС-01, АС-02, АС-03.
- При ошибке `quote_not_found` в `save_evidence` необходимо читать точные строки через `read_lines` и использовать точный текст из вывода инструмента для сохранения.
