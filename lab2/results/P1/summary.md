## Цель
Изучить документы в `data/search` по теме информационного поиска: выделить подходы, ограничения и спорные утверждения. Построить обзор (не более 1200 слов) с обязательными разделами: approaches, limitations, disputed, decisions, summary. Найти и дословно привести решения архитектурного совета (АС-01, АС-02, АС-03), решение кафедры о метрике качества и разбор инцидента INC-2026-017.

## Ограничения пользователя
- [C1] Каждый проверяемый вывод обзора ссылается на документ и страницу через evidence.
- [C2] Использовать только документы из data/search, без интернета.
- [C3] Обзор не длиннее 1200 слов.
- [C4] Спорные утверждения — отдельным разделом, с аргументами за и против.
- [C5] Решения архитектурного совета (АС-01, АС-02, АС-03) привести дословно с номером страницы.

## Решения и договорённости
- Использовать навык `analyze_large_docs` для работы с большими документами.
- План работы: инвентаризация → поиск по терминам → чтение найденных страниц → сбор evidence → формирование секций → проверка критериев.
- Критерии завершения: минимум 8 evidence, evidence в каждом документе области, наличие всех секций, дословные цитаты АС-01/02/03 в секции decisions.
- Harness hint: прекратить последовательное чтение строк, использовать `search_text` для поиска оставшихся мест, сохранить найденные цитаты как evidence и написать доступные секции отчета.
