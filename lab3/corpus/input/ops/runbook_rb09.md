# Runbook RB-09: восстановление хранилища чекпоинтов

Изменения конфигурации выкатывают постепенно и с возможностью отката.

## Шаги

Шаг 1: остановить запись новых задач.

Шаг 2: проверить контрольные суммы последней копии.

Шаг 3: переключить агентов на реплику; допустимое время переключения — 15 минут.

Шаг 4: запустить проверку целостности.

Изменения конфигурации выкатывают постепенно и с возможностью отката.

Метрики сервиса смотрят по перцентилям задержки, а не по среднему.

## Критерий успеха

Все активные задачи продолжаются с последнего чекпоинта без повторных эффектов.

Алерты настраивают на устойчивые нарушения порогов, а не на единичные выбросы.

Метрики сервиса смотрят по перцентилям задержки, а не по среднему.
