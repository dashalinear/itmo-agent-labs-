# Оценка агентов

Результат субагента включает статус, выводы, подтверждения и открытые вопросы.

## Трассы

Каждый запуск сохраняет трассу с вызовами инструментов и переходами графа.

Бюджет агента ограничивает токены, число вызовов и время выполнения.

Субагент получает задание на естественном языке и работает в собственном контексте.
