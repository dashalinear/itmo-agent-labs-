# Векторный поиск kNN в Elasticsearch

Полнотекстовый поиск опирается на инвертированный индекс и ранжирование по формуле BM25.

## Поле dense_vector

Векторы хранятся в поле dense_vector размерности 384 с косинусной мерой близости.

Фильтры по папке и типу документа сужают область поиска до ранжирования.

Длинные документы делят на фрагменты, чтобы найденный текст указывал на конкретное место.

## Параметры HNSW

Для индекса фрагментов задано m = 16 и ef_construction = 100; при запросе num_candidates = 50.

Векторный поиск сравнивает эмбеддинги запроса и фрагментов по косинусной близости.

Фильтры по папке и типу документа сужают область поиска до ранжирования.

## Модель

Эмбеддинги строит многоязычная модель paraphrase-multilingual-MiniLM-L12-v2 локально.

Кэш популярных запросов снижает нагрузку, но устаревает после переиндексации.

Точные коды и артикулы лучше искать по ключевому полю без анализатора.
