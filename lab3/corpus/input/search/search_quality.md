# Оценка качества поиска

Кэш популярных запросов снижает нагрузку, но устаревает после переиндексации.

## Метрики

Основная метрика проекта — nDCG@10, для навигационных запросов дополнительно считают MRR.

Полнотекстовый поиск опирается на инвертированный индекс и ранжирование по формуле BM25.

Подсветка совпадений помогает пользователю быстро проверить найденный фрагмент.

## Разметка

Каждый запрос размечают два асессора, расхождения разбирает третий.

Векторный поиск сравнивает эмбеддинги запроса и фрагментов по косинусной близости.

Точные коды и артикулы лучше искать по ключевому полю без анализатора.

## Решение по выкатке

Изменение выкатывают, только если nDCG@10 вырос статистически значимо (решение SRCH-418).
