# Гибридный поиск: правила объединения

Подсветка совпадений помогает пользователю быстро проверить найденный фрагмент.

## Объединение ветвей

Кандидаты из BM25 и векторной ветви объединяются методом Reciprocal Rank Fusion с параметром 60.

Качество поиска измеряют на размеченном наборе запросов, а не по отдельным примерам.

Полнотекстовый поиск опирается на инвертированный индекс и ранжирование по формуле BM25.

## Деградация

Когда задержка семантической ветви дольше десяти минут держится выше 450 мс, её выключают и отвечают только по BM25.

Длинные документы делят на фрагменты, чтобы найденный текст указывал на конкретное место.

Векторный поиск сравнивает эмбеддинги запроса и фрагментов по косинусной близости.

## Переранжирование

Кросс-энкодер переранжирует только первые 20 кандидатов.

Фильтры по папке и типу документа сужают область поиска до ранжирования.

Качество поиска измеряют на размеченном наборе запросов, а не по отдельным примерам.
