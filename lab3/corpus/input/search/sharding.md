# Шардирование индекса фрагментов

Точные коды и артикулы лучше искать по ключевому полю без анализатора.

## Число шардов

Индекс фрагментов учебного стенда имеет один первичный шард и ноль реплик.

Длинные документы делят на фрагменты, чтобы найденный текст указывал на конкретное место.

Полнотекстовый поиск опирается на инвертированный индекс и ранжирование по формуле BM25.

## Рост

При росте корпуса больше 5 миллионов фрагментов индекс разделяют на 3 шарда через операцию split.

Длинные документы делят на фрагменты, чтобы найденный текст указывал на конкретное место.

Подсветка совпадений помогает пользователю быстро проверить найденный фрагмент.
