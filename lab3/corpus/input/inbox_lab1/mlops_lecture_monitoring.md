# MLOps, занятие 5: мониторинг моделей в продакшене

Что мониторим после выката модели:
- технические метрики сервиса: задержка p95, доля ошибок, нагрузка;
- качество данных: пропуски, выбросы, схема входа;
- дрейф данных (data drift) и дрейф концепции (concept drift);
- бизнес-метрики, ради которых модель создавалась.

Для дрейфа признаков используют PSI (Population Stability Index):
PSI < 0.1 — изменений нет, 0.1–0.25 — умеренный дрейф, > 0.25 — значительный дрейф,
нужно разбираться и, возможно, переобучать модель.

Алерты настраиваем на устойчивое превышение порога, а не на единичный выброс,
иначе дежурные быстро перестают реагировать.

Практика: развернуть Evidently в docker-compose и построить отчёт о дрейфе
для датасета из лабораторной 2.
