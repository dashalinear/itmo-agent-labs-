## Цель
Обеспечить навигацию и извлечение информации из корпуса документов `itmo-lab3` по запросам пользователя: обзор структуры, поиск документов по событийной модели, анализу ограничений, поиску кодов ошибок, решений совещаний и политик резервного копирования с сохранением доказательств.

## Ограничения пользователя
В предоставленном фрагменте истории явных ограничений в формате `[C1]` из TASK CONTRACT не указано. Действуют стандартные правила работы с корпусом:
- Навигация по уровням L1 (структура) и L2 (текст).
- Обязательное сохранение доказательств (`evidence_id`) при цитировании.
- Точное копирование идентификаторов документов, фрагментов и строк.

## Решения и договорённости
- Для обзора корпуса используется инструмент `corpus_overview`.
- Для поиска документов применяется `search_fulltext` на уровне L1.
- Для получения структуры документа используется `get_l1`.
- Для чтения текста секций/фрагментов используется `read_section` / `read_fragment`.
- Для фиксации цитат используется `cite_fragment` с указанием `claim` и `kind`.
- Для поиска по точным строкам/паттернам используется `search_grep`.
- Для семантического поиска используется `search_vector` (модель `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2`).
- Для глубокого анализа используется `start_subagent` (kind: deep/exhaustive).
