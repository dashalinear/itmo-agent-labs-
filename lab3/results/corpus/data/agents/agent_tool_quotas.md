# Квоты на вызовы инструментов агента

## Назначение
Квота ограничивает число вызовов инструментов одного агента за сутки; код политики NEWDOC-2026-D.
Квоту задаёт администратор платформы для каждой команды отдельно.

## Значения по умолчанию
Не более 2000 вызовов инструментов в сутки на команду и не более 50 вызовов в минуту.
Вызовы веб-поиска считаются отдельно: не более 300 в сутки.

## Превышение
При превышении квоты новые вызовы отклоняются до начала следующих суток, текущая задача ставится на паузу.
Повышение квоты согласует руководитель платформы.
