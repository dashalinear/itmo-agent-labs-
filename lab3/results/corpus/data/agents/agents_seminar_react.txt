Семинар по агентным системам: паттерн ReAct

ReAct чередует рассуждение (reasoning) и действие (acting): модель решает,
нужен ли вызов инструмента, получает наблюдение и продолжает рассуждение.

В LangGraph готовый агент собирается фабрикой create_agent. Граф состоит из узла
модели и узла инструментов. Если ответ модели содержит tool calls, управление
переходит к узлу tools, затем результат возвращается модели. Если tool calls нет,
граф завершается.

История хранится в состоянии графа в списке messages; reducer add_messages
дописывает новые сообщения, а checkpointer сохраняет состояние по thread_id.

Важно ограничивать число шагов (recursion_limit), иначе зациклившийся агент
будет бесконечно вызывать инструменты.

Задание к следующему семинару: собрать агента с двумя инструментами и
показать трассу с переходами model -> tools -> model.
