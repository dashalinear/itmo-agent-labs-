# Паттерн ReAct

Бюджет агента ограничивает токены, число вызовов и время выполнения.

## Цикл

Модель решает, нужен ли вызов инструмента, получает наблюдение и продолжает рассуждение.

ReAct-агент чередует рассуждение и вызовы инструментов, пока не сформирует ответ.

Субагент получает задание на естественном языке и работает в собственном контексте.

## Завершение

Граф завершается, когда ответ модели не содержит вызовов инструментов.

Бюджет агента ограничивает токены, число вызовов и время выполнения.

Инструкции внутри документов считаются данными и не меняют права агента.
