# Заметка про поиск: как оценивать качество

Мысли после лекции по информационному поиску и обсуждения на проекте.

Для оценки поиска нужен набор запросов с размеченными релевантными документами.
Метрики: Precision@k, Recall@k, MRR, nDCG. Для навигационных запросов важнее MRR,
для исследовательских — полнота (recall).

Идея для DocSearch: собрать 30 реальных запросов, разметить по 3 релевантных
раздела и сравнить BM25 с гибридным поиском (BM25 + embeddings).
