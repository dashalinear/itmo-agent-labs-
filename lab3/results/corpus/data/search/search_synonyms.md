# Словарь синонимов для поиска

## Зачем
Словарь синонимов расширяет полнотекстовый запрос близкими терминами; код записи NEWDOC-2026-E.
Например, «чекпоинт» расширяется до «контрольная точка» и «снимок состояния».

## Обновление
Словарь обновляется раз в две недели по журналу запросов без результатов.
После обновления индекс переоткрывается, переиндексация документов не нужна.

## Ограничения
Синонимы не применяются к grep: точный поиск кодов остаётся буквальным.
