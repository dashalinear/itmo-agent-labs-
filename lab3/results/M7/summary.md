## Цель
Исследовать в корпусе подходы к хранению состояния агентов (agent state / persistence / memory), их различия по ограничениям и выбранный для DocSearch вариант. Дополнительно: полный обход папки `storage` на предмет всех упоминаний ограничений и проверка квот на вызовы инструментов.

## Ограничения пользователя
В предоставленном фрагменте явных ограничений формата `[C1]` из TASK CONTRACT не указано. Действующие правила взаимодействия:
- Ответы должны содержать подтверждения из текстов (цитаты с номерами строк/фрагментов).
- Фоновые задачи (subagents) работают в режиме non-blocking; статус проверяется по запросу.
- Итоговый ответ должен включать открытые вопросы.
