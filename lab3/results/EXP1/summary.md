## Цель
Провести исчерпывающий обзор всех документов в папке `storage` и перечислить все упоминания ограничений с указанием источников (документ, fragment_id, строки).

## Ограничения пользователя
*   Просмотри все документы папки storage и перечисли все упоминания ограничений с источниками (документ, fragment_id, строки).

## Решения и договорённости
*   Использовать инструмент `area_next` для последовательного чтения фрагментов (batches) документов.
*   Для каждого найденного упоминания ограничения использовать `record_mention` с указанием цитаты, заметки и fragment_id.
*   Фиксировать evidence_id, возвращаемый инструментом, для каждого записанного упоминания.
*   При исчерпании бюджета (budget exhausted) прогресс сохраняется, расход не сбрасывается, работа возобновляется с сохраненного курсора.
*   Использовать `area_grep` с regex-паттернами для верификации полноты поиска (по кодам `L-ST-\d+` и ключевым словам ограничений).
