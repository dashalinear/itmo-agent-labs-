## Цель
Обеспечить диалог пользователя с основным агентом по корпусу документов `itmo-lab3`: обзор структуры, полнотекстовый, векторный и grep-поиск, извлечение структуры документов, чтение фрагментов и цитирование ограничений/решений с сохранением доказательств.

## Ограничения пользователя
В предоставленном фрагменте истории явных пользовательских ограничений (TASK CONTRACT с тегами [C1]...) не указано. Действуют стандартные правила работы с корпусом:
- L1-резюме используется только для навигации, не является доказательством.
- Для подтверждения выводов необходимо читать L2 (read_section / read_fragment).
- Цитирование требует сохранения evidence_id.

## Решения и договорённости
- Для обзора корпуса используется инструмент `corpus_overview`.
- Для поиска по содержанию на уровне структуры используется `search_fulltext` с уровнем `L1`.
- Для поиска по смыслу используется `search_vector` (модель `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2`).
- Для получения структуры документа используется `get_l1`.
- Для чтения текста раздела/фрагмента используется `read_section` / `read_fragment`.
- Для фиксации цитаты как доказательства используется `cite_fragment` с указанием `kind` (например, "limitation", "decision", "fact").
- Для поиска по точным строкам/паттернам (включая regex) используется `search_grep`.
- При ошибке `quote_not_found` в `cite_fragment` необходимо использовать `open_source` для точного извлечения строки или корректировать цитату (убирать лишние знаки препинания/префиксы).
