## Цель
Просмотреть все документы в папке `storage` и перечислить все упоминания ограничений с указанием источников (документ, fragment_id, строки).

## Ограничения пользователя
*   Просмотри все документы папки storage и перечисли все упоминания ограничений с источниками (документ, fragment_id, строки).

## Решения и договорённости
*   Использовать инструмент `area_next` для последовательного чтения фрагментов (batches) документов.
*   Для каждого найденного упоминания ограничения вызывать `record_mention` с цитатой и примечанием.
*   Фиксировать `evidence_id` для каждого записанного упоминания.
*   При ошибке валидации курсора использовать точное значение `next_cursor` из предыдущего ответа инструмента.
*   Использовать `area_grep` с регулярным выражением `L-ST-\d+` для верификации полноты найденных упоминаний.
*   Дополнительно использовать расширенные регулярные выражения (ключевые слова: "не более", "нельзя", "ограничение" и др.) для поиска семантических упоминаний, не содержащих явных кодов L-ST.
