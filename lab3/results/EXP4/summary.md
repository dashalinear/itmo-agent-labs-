## Цель
Провести исчерпывающий анализ всех документов в папке `storage` (корпус `itmo-lab3`) для выявления и фиксации всех упоминаний ограничений. Результатом должен быть список записей с указанием источника: путь к документу, `fragment_id` и номера строк.

## Ограничения пользователя
[C1] Просмотри все документы папки storage и перечисли все упоминания ограничений с источниками (документ, fragment_id, строки).

## Решения и договорённости
- Использовать инструмент `area_next` для последовательного чтения фрагментов (batches) папки `storage`.
- Для каждого найденного упоминания ограничения вызывать `record_mention` с цитатой и примечанием.
- Фиксировать `evidence_id`, возвращаемый инструментом, для каждой записи.
- Продолжать процесс до получения `done: true` от `area_next`.
- Использовать `area_grep` для верификации полноты поиска по ключевому слову «Ограничение».
