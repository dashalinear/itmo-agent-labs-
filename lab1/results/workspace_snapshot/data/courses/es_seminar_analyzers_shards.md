# Конспект семинара: анализаторы и шарды в Elasticsearch

Анализатор = character filters + tokenizer + token filters.
Встроенный анализатор russian включает стоп-слова и стеммер для русского языка.
Для полей, по которым нужен точный фильтр (идентификаторы, пути), используем тип keyword.

Индекс делится на шарды; число основных шардов задаётся при создании индекса
и потом не меняется без reindex. Реплики повышают отказоустойчивость и пропускную
способность чтения. Для учебного стенда достаточно одного шарда и нуля реплик.

Запрос multi_match ищет по нескольким полям, можно задавать веса: text^3, title^2.
Подсветка (highlight) возвращает фрагменты с найденными словами.
