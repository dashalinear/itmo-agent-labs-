# Проект: рекомендательная система элективных курсов

Задача: рекомендовать студенту магистратуры элективы по истории выбранных курсов
и оценкам.

Данные: анонимизированные записи о выборе курсов за 2022–2026 годы,
около 12 000 пар «студент — курс».

Подходы:
- базовый: популярность внутри направления подготовки;
- коллаборативная фильтрация (ALS) по матрице выбора;
- гибрид с признаками курсов (теги, преподаватель, нагрузка).

Метрики офлайн-оценки: Precision@5, Recall@10, покрытие каталога.
Ограничение: холодный старт для новых курсов — используем теги.

Срок защиты проекта — 18 декабря.
