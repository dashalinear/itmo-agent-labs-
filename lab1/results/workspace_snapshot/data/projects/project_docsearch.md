# Проект DocSearch: описание и архитектура

DocSearch — учебный проект команды из четырёх человек: поисковая система
по документации кафедры.

## Компоненты
1. Загрузчик: читает Markdown и TXT, режет на разделы, сохраняет путь и номера строк.
2. Индекс Elasticsearch: поля text, title, path, section; анализатор russian.
3. API поиска: принимает запрос, возвращает фрагменты с подсветкой и ссылкой на файл.
4. Веб-интерфейс: строка поиска и список результатов.

## Требования
- ответ содержит путь к исходному документу и диапазон строк;
- переиндексация не создаёт дублей: ключ фрагмента стабилен;
- время ответа p95 < 300 мс на корпусе до 10 000 документов.

## Статус
Готов прототип загрузчика, индекс поднят в Docker. Следующий шаг — API.
