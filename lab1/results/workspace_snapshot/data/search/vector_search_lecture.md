# Лекция 7. Векторный поиск и HNSW

Курс «Информационный поиск».

Векторный (семантический) поиск сравнивает эмбеддинги запроса и документов,
обычно по косинусной близости. Точный перебор дорог, поэтому используют
приближённый поиск ближайших соседей (ANN).

HNSW (Hierarchical Navigable Small World) строит многоуровневый граф:
поиск начинается на верхнем разреженном уровне и спускается вниз.
Параметры: M — число связей вершины, ef_construction — ширина поиска при построении,
ef_search (num_candidates) — при запросе.

В Elasticsearch векторное поле имеет тип dense_vector, запрос — knn.
Гибридный поиск объединяет BM25 и kNN, например через RRF.
