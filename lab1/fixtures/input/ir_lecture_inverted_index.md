# Лекция 3. Инвертированный индекс и ранжирование BM25

Курс «Информационный поиск», осенний семестр 2026. Лектор: доц. Смирнова.

## Инвертированный индекс
Инвертированный индекс сопоставляет каждому терму список документов (posting list),
в которых этот терм встречается. Для каждого вхождения хранится идентификатор документа,
частота терма и, при необходимости, позиции для фразового поиска.

Построение индекса: токенизация, нормализация (нижний регистр), удаление стоп-слов,
стемминг или лемматизация. Для русского языка стемминг заметно повышает полноту.

## Сжатие списков
Posting lists сортируются по docID и хранятся как разности (gap encoding),
затем сжимаются кодами переменной длины (VByte) или блоками (PForDelta).

## BM25
Формула BM25 учитывает частоту терма (tf), обратную документную частоту (idf)
и длину документа. Параметры по умолчанию: k1 = 1.2, b = 0.75.
Параметр b управляет нормализацией по длине: при b = 0 длина документа не учитывается.
