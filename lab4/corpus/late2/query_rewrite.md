# Переписывание запросов перед поиском

## Идея
Перед поиском запрос пользователя переписывается моделью: раскрываются сокращения и коды документов.
Код решения: SRCH-RW-3.

## Ограничение
Переписанный запрос не может быть длиннее 300 символов; исходный запрос сохраняется в трассе рядом с переписанным.
