# Доступность интерфейса платформы агентов

## Требования
Веб-интерфейс платформы должен соответствовать уровню AA рекомендаций WCAG 2.2; код требования ACC-2026-01.
Контраст текста — не ниже 4,5:1, все действия доступны с клавиатуры.

## Проверка
Перед каждым релизом интерфейс проверяется автоматическим аудитом доступности и вручную с экранным диктором.
Найденные нарушения уровня A блокируют релиз.

## Ответственный
За доступность отвечает дизайнер интерфейса Ольга Лебедева; отчёт аудита прикладывается к релизу.
