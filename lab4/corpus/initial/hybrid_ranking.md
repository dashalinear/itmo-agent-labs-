# Гибридное ранжирование

## Идея
Результаты BM25 и векторного поиска объединяют методом Reciprocal Rank Fusion (RRF).
Константа RRF в стенде — 60.

## Когда помогает
Гибрид полезен, когда запрос содержит и точный термин, и смысловую формулировку.

## Ограничения
RRF не учитывает абсолютные значения score, только позиции.
Для полного перечисления гибридный top-k не подходит: он отсекает хвост результатов.
