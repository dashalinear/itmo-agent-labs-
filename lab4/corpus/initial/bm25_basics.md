# Полнотекстовый поиск BM25

## Принцип
BM25 ранжирует документы по частоте термина в документе и его редкости в коллекции.
Длина документа нормализуется параметром b, насыщение частоты — параметром k1.

## Настройки стенда
В учебном индексе k1 = 1.2 и b = 0.75 (значения Elasticsearch по умолчанию).
Анализатор для русского языка использует стемминг snowball.

## Ограничения
BM25 не находит перефразированные формулировки без общих слов.
Точные коды вроде SRCH-404 лучше искать grep, а не ранжированным поиском.
