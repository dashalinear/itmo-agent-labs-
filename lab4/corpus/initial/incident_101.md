# Разбор инцидента INC-2026-101

## Что произошло
14.11.2026 агент индексации не мог записывать чекпоинты 40 минут.
Причина — база SQLite лежала на сетевом диске, блокировки зависали.

## Действия
Дежурный перенёс базу на локальный диск и перезапустил worker.
Незавершённые задачи продолжились с последнего чекпоинта без потери прогресса.

## Выводы
Решение ST-CHK-01 дополнено запретом сетевых дисков.
Для нескольких процессов используется PostgreSQL по решению РС-12.
