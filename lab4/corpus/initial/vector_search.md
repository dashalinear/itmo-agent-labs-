# Векторный поиск по embeddings

## Модель
Фрагменты кодируются моделью embeddings размерности 384.
Векторы хранятся в поле dense_vector и ищутся kNN по косинусной близости.

## Индекс HNSW
Параметр m = 16, ef_construction = 100.
Чем больше num_candidates, тем выше полнота и тем медленнее запрос.

## Ограничения
Векторный поиск плохо различает близкие коды и номера версий.
После смены модели embeddings индекс нужно перестроить целиком.
