# Чекпоинты агента в SQLite

## Назначение
SQLite используют для локальных чекпоинтов одного рабочего процесса агента.
После каждого шага графа состояние записывается в файл checkpoints.db.
Код решения: ST-CHK-01.

## Ограничения
SQLite допускает только одного писателя: при параллельной записи второй процесс ждёт блокировку.
Файл базы нельзя размещать на сетевом диске: блокировки на SMB работают ненадёжно.
Размер одного чекпоинта в учебном стенде не превышает 2 МБ.

## Восстановление
После аварийной остановки процесс открывает тот же файл и продолжает с последнего чекпоинта.
Повтор шага возможен: инструменты с побочными эффектами должны быть идемпотентными.
