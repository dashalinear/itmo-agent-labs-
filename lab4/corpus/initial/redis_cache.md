# Redis как кэш состояния между шагами

## Назначение
Redis хранит промежуточное состояние агента между шагами, когда важна скорость, а не долговечность.

## Ограничения
TTL записей состояния — 24 часа; после истечения состояние теряется.
Redis не заменяет основной бэкенд чекпоинтов: при перезапуске без persistence данные пропадают.
Максимальный размер значения в стенде — 512 КБ.

## Практика
Ключи строятся как agent:{task_id}:step:{n}, чтобы повтор шага перезаписывал ту же запись.
